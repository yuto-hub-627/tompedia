# 紹介動画（2本）― 要件確認の質問

作る動画は2本です。

| | ① アプリ「とんペディア」紹介動画 | ② 団体「とんペディア_ラボ」紹介動画 |
|---|---|---|
| 伝えること | アプリで何ができるか、なぜ使うべきか | ラボの理念と活動内容 |
| 主な素材 | Drive `とんペディア紹介動画` フォルダ（`tonpedia_pop.mp4`・`とんペディア紹介用.MP4`）、`Figma用` のアプリ画面収録 | Googleドキュメント「とんペディアラボ紹介動画台本」、活動風景、スライドの Vision・メンバー・実績 |
| 長さ | 未定（Q8） | 30秒ぐらい（台本ドキュメントより） |

各質問の `[Answer]:` の後ろに回答を書いてください（選択肢の記号だけでもOK、補足は自由に）。
迷ったら **（推奨）** の選択肢で進めます。素材の一覧は `00-material-inventory.md` にあります。

### Q2. 10MBを超える動画の受け渡し方法
このセッションのDrive連携は **1ファイル10MBまで** しか読み込めないため、アプリの画面収録（`Figma用` フォルダの13本）と `とんペディア紹介用.MP4`（99MB）は、今のままでは使えません。

- B. 自分で共有設定を「リンクを知っている全員」に変える（終わったら連絡する）
- C. 自分で10MB以下に圧縮（または必要な部分だけ切り出し）して、Driveにアップし直す
- D. 動画素材は使わない（静止画、とん平イラスト、ロゴのアニメーションだけで作る）

## このあとの進め方（AI-DLC）

動画ごとに以下を進めます（Q0で決めた順番で）。

1. **要件確認（今ここ）**：この質問に回答 → `02-requirements.md` に要件をまとめて確認してもらう
2. **設計**：台本・絵コンテ（秒単位の構成、テロップの文言、使う素材）を `03-storyboard-app.md` / `03-storyboard-labo.md` にまとめ、静止画のプレビューで確認してもらう
3. **制作**：動画を書き出し、プレビューを確認してもらう → 修正
4. **納品**：Drive にアップロード（②は台本ドキュメントにも反映）
