### Q11. 構成はどれにしますか？（30秒の場合の案です。秒数はおおよそ）

**A. 「理念 → 3つの活動 → 成果」型**（推奨。台本ドキュメントの目的にいちばん合う）
| 秒 | 内容 |
|---|---|
| 0–3 | ロゴアニメ（`tonpedia_pop.mp4`）→「東北大生が、自分のやりたいことを もっともっと。」 |
| 3–8 | 課題：「大学生活の情報、足りてる？」（情報不足・不公平） |
| 8–20 | 3つの部署を順に：**開発**（アプリ画面）／**営業**（企業とのイベント）／**広報**（SNS） |
| 20–26 | 成果の数字：ユーザー6,720名、新入生の95%が登録、メンバー87名 |
| 26–30 | 「とんペディア_ラボ」ロゴ ＋ Instagram 等の誘導、とん平「CHECK!」 |

**C. 「数字で殴る」型**（テンポ重視・企業向け）
ほぼ数字とアプリ画面だけをリズムよく切り替える。6,720名 → 95% → 1,000人/日 → 87名 → 126%。
