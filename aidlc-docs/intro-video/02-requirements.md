# 紹介動画 ― 要件まとめ

`01-requirement-questions.md` の回答をまとめたものです。

## 進め方
- **①アプリ「とんペディア」紹介動画を先に作る。締め切り：明日（2026-10-21）**
- ②「とんペディア_ラボ」紹介動画は保留。台本は依頼者が作成し、完成後にこちらから必要な写真（内容・枚数）を伝える。決まった台本はDriveの台本ドキュメントに書き込んでよい。

## 共通
| 項目 | 内容 |
|---|---|
| 画面 | 縦 1080×1920（Instagram リール・TikTok・YouTube ショート） |
| トーン | ポップで明るい。紫×白、テンポよく文字が弾む（ロゴアニメ `tonpedia_pop.mp4` と同じ雰囲気） |
| とん平 | 要所で2〜3回（オープニング付近、締めの「CHECK!」など） |
| 音 | ナレーションなし、テロップのみ。**BGMなし**（音楽は後で依頼者が決める） |
| 納品 | Driveの `とんペディア紹介動画` フォルダに MP4（H.264、30fps）。台本・構成の資料はこのリポジトリに残す |
| 動画素材 | 10MB超の動画は、共有設定を一時的に「リンクを知っている全員」にして取得し、取得後に戻す |

## ① アプリ「とんペディア」紹介動画
| 項目 | 内容 |
|---|---|
| 長さ | 30秒 |
| 見せる相手 | 新入生・まだ使っていない東北大生、すでに使っている人。**東北大生以外の人も見る**前提（学内用語には一言説明を添える。例：鬼仏表＝授業の評価がわかる） |
| 映像の作り | `とんペディア紹介用.MP4`（アプリの操作画面）を背景に流し、**白の半透明の膜で薄くした上に紹介文を乗せる** |
| 主役の機能（この順） | 1. 時間割 2. 鬼仏表 3. シラバス検索 |
| その他の機能 | 「こんな機能もあります！」でさくっと紹介：空き教室検索、地下鉄・バス時刻表、GPA計算機、サークル紹介、イベント掲示板 |
| 数字 | ユーザー数 6,720名、今年度新入生の登録率 95%、DAU 約1,800人/日 |
| 構成 | 「あるある → 解決」型（Q14-A） |
| 最後の誘導 | ホームページ https://info.tompedia.jp/ |
