## 全体の振り返り
Good
- 15団体ほどと票交換で連携できた
- 動画作成を効率化できた → 今後の量産へ
- 動画を出せた → 企業賞を狙いに行く
- なるべく20時にリマインドした → 票交換先への投票を促した
- 連携団体を増やせた

More
- リマインドを1回忘れた → ボットで自動化したい
- 動画を1本しか出せていない → GC前に最低5本作りたい
- 票交換の打診が遅かった → 10月に入ったらすぐ始める
- 他団体とは票交換の連携しかできなかった → ほかにも連携して何か面白いことをしたい
- 連携団体からもらえる票数も考えて、獲得票数の見込みを出す → より計画的に進められる
