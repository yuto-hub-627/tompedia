# ③ Giving Campaign 感謝動画：要件

`01-requirement-questions.md` の回答をまとめたもの。

| 項目 | 内容 |
|---|---|
| 目的 | Giving Campaign 2026 で応援投票してくれた方、とんペディアを使ってくれている方に、感謝の気持ちを伝える |
| 主役 | **感謝の気持ち**。そのうえで、ちょっとした実績と、これからの方針（MVV）を見せる |
| 形と長さ | 縦 1080×1920、30fps、29秒ぐらい |
| 雰囲気 | これまでの動画と同じポップな感じ |
| 声 | ナレーションあり（メンバーが読んで録音する）。最後に「これからもよろしくお願いします！」のみんなの声 |
| 最初のロゴ画面 | これまでと同じ形で1.8秒。ロゴは「とんペディア_ラボ」 |
| BGM | 新しい曲。候補を3つ出して選んでもらう（`03-storyboard.md` の「BGM」）。ロゴ画面から切り替わる 1.8秒 から始める |
| GCの結果 | 応援 **319票**、25位、獲得額 8,544円。ナレーションでは「319票もの応援」を言う |
| 実績 | アプリ「とんペディア」現在 6,720人が利用中／企業と連携したイベント（イベントレポートの表紙） |
| MVV | Canva「【公開版】とんペディア紹介資料」より。動画では Mission「すべての東北大生に最高の価値を届けて、東北大学を世界一おもしろい大学にする」と、Value の「つくろう！まなぼう！つながろう！」を出す（見せ方の質問は空欄だったので、30秒に収まるこの形にした） |
| 名前の出し方 | とんペディア_ラボ（Tompedia Lab） |
| 写真 | 全体写真（Drive `IMG_4835.JPG`。Canva の GC 参加表明の投稿にも使っているもの） |
| GCの画像 | Canva の GC 投稿画像（DAHYForzA3E）を使う |
| 最後の誘導 | 「くわしくはホームページへ」（URLは画面に出さない） |
| Instagram 投稿文 | 作る（Driveにも保存） |
| 締め切り | 今週中（2026-11-01 まで） |
