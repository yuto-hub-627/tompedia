# ② 団体「とんペディア_ラボ」紹介動画：要件

`01-requirement-questions.md` の回答をまとめたもの。

| 項目 | 内容 |
|---|---|
| 目的 | ラボの理念・活動内容・これからの挑戦を、東北大生と学外の人に伝える |
| 主役 | **団体としてのとんペディア_ラボ**。アプリとイベントは「ラボの実績」として短めに見せる。画面はなるべくメンバーの写真・動画を使う |
| 形と長さ | 縦 1080×1920、30fps、33秒ぐらい（GC版は最後に投票お願いカードが付いて36秒ぐらい） |
| 雰囲気 | アプリ動画と同じポップな感じ。ただし冒頭のスローガンだけ、黒背景・白文字・「ドーン」で引き締める |
| 声 | ナレーションあり（メンバーが読んで録音する）。最初のスローガンは低い声。最後に「とんペディアラボ！」のみんなの声 |
| 最初のロゴ画面 | アプリ動画と同じ形で1.8秒。ロゴは「とんペディア_ラボ」。声は入れない |
| BGM | アプリ動画とは別の曲。候補を3つ出して選んでもらう（`03-storyboard.md` の「BGM」） |
| GC版 | 作る（普通版とGC版の2本。アプリ動画と同じ投票お願いカード） |
| 最後の誘導 | 「くわしくはホームページへ」（https://info.tompedia.jp/ 。URLは画面に出さない） |
| 写真・動画 | 活動風景・イベント・開発／営業／広報・集合写真。顔出しは全員OK。必要なものは `03-storyboard.md` の「お願いしたい素材」 |
| イベントの見せ方 | これまでのイベントレポート（Canva）の表紙を並べて、どんなイベントをしてきたかをざっと見せる |
| ロゴ・とん平 | 適宜使う |
| 出す数字 | アプリは「2025年4月1日リリース、現在6,720人が利用中」と言う（依頼者の指定）。30秒に収めるため、新入生の登録率・クラファン実績・設立日・活動場所・毎日の利用者数は出さない |
| 出さないもの | メンバー数 |
| Instagram 投稿文 | 作る（普通版・GC版。Driveにも保存） |
| 締め切り | 2026-10-24（→ 2026-10-29 に見送り。写真・録音待ちのまま保留） |
| 台本 | 依頼者の台本をもとに、30秒に収まるようナレーションを短くした版を `03-storyboard.md` に書いた。決まったらDriveの台本ドキュメントに書き写す |
