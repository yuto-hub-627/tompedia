## 調査でわかったこと（前提）

1. 公式テンプレートはブランドテンプレート `EAG_b_rCz2M`（22ページ）。オートフィル用のフィールドは設定されていないので、**「型ページを複製 → 文字を差し替え」方式**で作る（イベントレポートと同じ方式）。
2. MCPで新しく足したテキストはテンプレートのフォントにならない。なので、文字が入る場所は型のテキスト要素を使い回すしかない。図形（ボックス・矢印）は追加できる。
3. 自由に使える汎用の型は11種類（表紙3・目次・章扉・見出し＋本文・空カード・写真メッセージ・アプリ表紙）。残りの11ページはとんペディア紹介資料の完成ページ（機能紹介・KPI・沿革など）。
4. 箇条書きや「理想／現状」の比較など、よく使う型がテンプレートにない。実例（`DAHXIFJiZ5I` ありたい姿と現在地）にはある。
5. アカウントには別の `tonpedia-slides` スキル（PowerPoint版・24型）があるが、Canvaのテンプレートと型が一致していない。
