# イベントメモのテンプレート

Google ドライブ「tompedia / イベント」にある「イベントメモ_テンプレート（コピーして使う）」と同じ中身（正本はドライブ）。
https://docs.google.com/document/d/1eQhzxCmVkHGcplzyBUu_7bgQcLXoREEp-8fejtXdh6Q/edit

- フォルダ：`tompedia / イベント / YYYY-MM-DD_イベント名`
- 中身：「メモ」（このテンプレートのコピー）＋写真（表紙にしたい写真は「表紙_」から始める）＋（B型なら）企業ロゴの画像

項目：イベントの正式名称／開催日／開催場所／主催・共催・協賛・協力／企業ロゴの有無／対象者／参加人数／開催の背景・目的／当日のプログラム／登壇者・講師／印象に残った場面／参加者の声／謝辞の相手／Discord・Slack の報告（貼りつけ）
