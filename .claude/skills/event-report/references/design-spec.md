# デザイン仕様（イベントレポート）

既存のCanvaデザインから要素データを読み取って定義した仕様。座標の単位はpx、原点はページの左上。
数値は「型を複製したあとに崩れていないか」を確かめるための基準として使う。フォントは `fontRef` でしか識別できない（Canva MCPからは変更できない）ため、テキストは必ず型の既存要素を `replace_text` して使う。

## 共通

| 項目 | 値 |
|---|---|
| キャンバス | 1080 × 1350（Instagram 4:5）、1ページ＝1スライド |
| メインカラー（紫） | `#825dab` |
| 日付の文字色（A型・濃い紫） | `#533970` |
| 本文の文字色（グレー） | `#545454` |
| 写真の暗幕 | `#212121`、不透明度 0.3（表紙の見出しの下に敷く） |
| 白 | `#ffffff` |

### フォント（fontRef）
| 用途 | fontRef | ウェイト | サイズ |
|---|---|---|---|
| 「Event Report」 | `YAFdJnQq22A` | bold | 100 |
| 表紙の大見出し・サブタイトル・「イベント開催報告」 | `YAFdJiHXlcI` | heavy／bold／light | 84〜87／40／33 |
| 日付・「swipe →」・「Photo Collection」 | `YAFdtQi73Xs` | normal／heavy | 54／24／93 |
| 本文・縦見出し・キャプション | `YAFd-NWSSIw` | normal〜medium | 29.33／48／29〜35 |
| 「Sponsored by」（B型のみ） | `YAFcfgcNhWk` | medium | 42 |

### 固定要素（編集しない）
- **フッターロゴ**：Tompedia Laboのロゴ画像（mediaId `MAG3UFawsNI`）。表紙の右下、位置 (697, 1265)、サイズ 337×43、ロック済み。
- **クロージングページ**：最終ページ。背景がノートPCの写真＋中央に白のTompedia Laboロゴ（mediaId `MAG5Dpx1dCM`）。要素はなし。全レポート共通。
- **本文ページの罫線**：紫 `#825dab`、太さ2px。上は y≈107、下は y≈1241。
- **「swipe →」**：紫、24px、字間0.191、中央揃え、y≈1263。クロージングページ以外のすべての本文ページに入る（表紙には入らない）。

## A型：自主開催（白文字）

### 表紙（P1）
```
┌───────────────────────────────┐ y=0
│ Event Report（白・100px）       │ 紫帯（背景 #825dab）
│ [イベント開催報告]（白・33px light、紫ラベル）│
├───────────────────────────────┤ y=135
│ 写真（1080×1080、全幅）              ( 2026 )│ ← 白丸 Ø234 @(780,206)
│                                     ( 06.23)│   日付 #533970 54px 中央揃え
│ ▓暗幕 #212121 30%（左寄せ、x=-31, 幅897）    │
│ 大見出し（白・heavy・84〜87px）@(36,437) 幅852 │
│ 行間1.2・字間0.05・3〜4行                    │
│ サブタイトル（白・bold・40px）@(36,≈900)       │
│ 1〜2行（イベントの正式名称）                   │
├───────────────────────────────┤ y=1215
│                        Tompedia Labo ロゴ │ 紫帯
└───────────────────────────────┘ y=1350
```
- 写真枠：shape（`isMediaReplaceable: true`）、top 135、1080×1080、ロック済み。
- 暗幕の高さは見出しとサブタイトルの量に合わせて調整してよい（01では870、13では428）。

### 本文ページの共通ルール
- 背景は白、上下に紫の罫線、下に「swipe →」。
- 本文：#545454、29.33px、行間1.5、字間0.085、両端揃え（justify）。
  - 全幅のとき：x=108、幅864（1行あたり約27文字）
  - 縦見出しと並ぶとき：x≈269、幅699（1行あたり約22文字）
- 段落の間は1行空ける。段落の頭は全角スペース「　」（02、03、04、13、15で統一されている）。
- 写真は余白（左右108）に揃えて置く。写真の枠線はなし。

### ページのパターン（A型）
| ID | 名前 | レイアウト | 実例 |
|---|---|---|---|
| A-intro | 縦見出し＋導入 | 左に縦見出し（x=84、48px medium、紫、行間1.66、最大19文字）。右上に写真（706×445 @266,198）、その下に本文（幅699、約200文字まで）。上の罫線は x=266〜968 | 01 P2、02 P2、04 P2、14 P2 |
| A-photo-text | 写真＋本文 | 上に写真1〜2枚（幅最大860、高さ300〜530）、下に本文（全幅、約150〜250文字） | 03 P2、14 P3、15 P2 |
| A-text-photo-text | 本文＋写真＋本文 | 本文 → 写真2枚（紫のキャプション付き）→ 本文 | 03 P3、04 P3、04 P4 |
| A-caption | 写真＋キャプション | 写真2〜3枚を左右にずらして配置し、紫のキャプション（29〜35px、2〜3行）を添える。吹き出しの装飾（紫に再着色した画像）を使ってもよい | 01 P3、01 P4、03 P4 |
| A-thanks | 縦見出し「ご参加ありがとうございました」 | 右に縦見出し（x=915）、左上に写真（674×505 @120,153）、その下に本文（幅699）。罫線は x=108〜813 | 01 P5、14 P4 |
| A-photo | Photo Collection | 左に縦書きの「Photo Collection」（93px heavy、紫、90度回転）。写真8枚のコラージュ＋マスコットのイラスト。03のように上に横書きのタイトルを置く形も可。写真が多ければタイトルなしのコラージュページを1枚追加 | 01 P6、03 P6〜7 |
| END | クロージング | 固定 | 全レポート |

### ページ構成の例（A型）
- 標準（7ページ）：表紙 → A-intro → A-caption → A-caption → A-thanks → A-photo → END（01）
- 短め（4〜5ページ）：表紙 → A-intro → A-photo-text → A-thanks → END（14）／表紙 → A-photo-text ×2 → END（15）
- 長め（8ページ）：表紙 → A-photo-text → A-text-photo-text → A-caption → A-photo-text → A-photo ×2 → END（03）

## B型：企業とのイベント（紫文字）

### 表紙（P1）
```
┌───────────────────────────────┐ y=0
│ 紫の細帯（y=0〜33）                    │
├───────────────────────────────┤ y=33
│ Event Report（紫 #825dab・100px）@(36,60)│ 白帯（1080×277）
│ Sponsored by（#545454・42px）@(44,226)  [企業ロゴ]│ ロゴ枠 @(301,169) 約335×138
├───────────────────────────────┤ y=309
│ 写真（1080×906）                    ( 2026 )│ ← 紫丸 Ø234 @(800,250)
│                                     ( 06.23)│   日付は白 54px（白帯と写真の境目にまたがる）
│ ▓暗幕 #212121 30% @(-31,367) 897×428      │
│ 大見出し（白・heavy・84px）@(36,437) 幅853   │
│ 3行（「〇〇様と／〜の／イベントを開催！」）    │
├───────────────────────────────┤ y=1215
│                        Tompedia Labo ロゴ │ 紫帯（1080×135）
└───────────────────────────────┘ y=1350
```
- 「イベント開催報告」のラベルはない。
- サブタイトルは基本的になし（08のように入れる場合は大見出しの下、白の40px）。
- ロゴは横長の画像に差し替える。必要なら `crop_media` で余白を調整する。

### 本文ページ（B型）
- 縦見出しは使わず、写真＋本文のシンプルな構成にする。本文の書式はA型と同じ。
- B-photo-text：上に写真1〜2枚（2枚なら互い違いに重ねる。13 P2）、下に本文（全幅、約250〜300文字）。
- B-photo-text-long：上に写真1枚（860×530）、下に本文2段落（13 P3）。
- 1ページに全文をまとめる場合（05）：上に写真（860×約300）、下に本文（約400文字）。

### ページ構成の例（B型）
- 標準（4ページ）：表紙 → B-photo-text → B-photo-text-long → END（13）
- 最短（3ページ）：表紙 → 1ページ完結 → END（05）
- Photo Collectionはなし（入れる場合はA型のA-photoページを流用する）。

## 文字数の上限（はみ出し防止）
| 要素 | 1行あたり | 上限 |
|---|---|---|
| 表紙の大見出し | 6〜9文字 | A：4行／B：3行（改行は `\n` で明示する） |
| 表紙のサブタイトル | 約20文字 | 2行 |
| 縦見出し | — | 19文字 |
| 本文（幅699） | 約22文字 | 1ページ約200文字（写真あり） |
| 本文（幅864） | 約27文字 | 写真ありで約250〜300文字、写真が小さければ約400文字 |
| 紫のキャプション | 7〜12文字 | 3行 |
