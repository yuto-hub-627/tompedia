# レイアウトカタログ（とんペディア スライドテンプレート）

複製元 `DAHQTwPXwu4`（＝ブランドテンプレート `EAG_b_rCz2M`）の22ページを、用途ごとの「型」として整理したもの。
番号はページ番号（1始まり）で、`copy-design` / `merge-designs` の `page_numbers` にそのまま使える。

- **汎用の型**：文字を差し替えるだけで何にでも使えるページ。自動生成ではこれを主に使う。
- **実例ページ**：とんペディア紹介資料の完成ページ。内容がほぼ同じとき（団体紹介・アプリ紹介）にだけ流用し、数字は最新に更新する。レイアウトの参考としても使う。
- 要素IDの `LB…` は原本 `DAHQTwPXwu4` の値。複製後も同じかは未検証で、ページID（`PB…`）は変わる。作業では必ず複製後のデザインを `read-design`（`open_transaction: true`）で読み直して locator_id を取る。
