# デザイン仕様（とんペディア スライドテンプレート）

Canvaの公式テンプレートから要素データを読み取って定義した仕様（2026-10-19 時点）。
座標の単位はpx、原点はページの左上。数値は「型を複製したあとに崩れていないか」「新しく要素を足すときにどこに置くか」の基準として使う。

フォントは `fontRef` でしか識別できず、Canva MCPの `add_text` で作ったテキストはテンプレートのフォントにならない（`format_text` でも書体は変えられない）。**テキストは必ず型の既存要素を `replace_text` して使う。** 足りないときは、同じ型のページをもう1枚複製するか、同じページの既存テキスト要素を流用する。

## フレーム（ページの外枠）は4種類

### F1：表紙フレーム（アプリ表紙）— P1、P11
```
┌──────────────────────────────────────────┐ 背景 #f6efff
│▓紫ブロブ（左上）                  スマホ画面×6（右側、-36°）│
│                                    薄紫ブロブ（右下）      │
│ [アイコン]とんペディア  @(108,458)                        │
│ スライドタイトル  64px bold #242323 @(123,645) 幅863     │
│ 所属 名前        56px heavy #825dab @(123,835) 2行       │
└──────────────────────────────────────────┘
```
- 左半分（x 100〜1000）が文字の領域。右半分はスマホのモックアップなので触らない。
- P11は「東北大生のためのアプリ」（43px normal）＋ロゴの組み合わせ。アプリ紹介の表紙・締めに使う。

### F2：曲線フレーム（白×紫）— P2（How to表紙）、P4（目次）
```
┌──────────────────────────────────────────┐
│ 白ブロブが左側を覆う（背景の紫が右下に見える）         │
│ 文字は左 x≈146、幅764                    クローバー白 │
│                                         (1218,363)  │
└──────────────────────────────────────────┘
```
- P2：背景 `#825dab`、P4：背景 `#efe0ff`（薄紫）。ブロブはロック済み。
- 文字は x 140〜1150 に収める（右はクローバーと曲線）。

### F3：扉フレーム（紫ブロブ）— P5、P10
```
┌──────────────────────────────────────────┐ 背景 #eddeff
│▓▓▓紫ブロブ（左上〜中央）▓▓▓       Tompedia(紫) 右上 │
│ ┃ 01           199px heavy 白 @(215,181)            │
│ ┃ 章タイトル    85px bold 白 @(215,451) 2行まで      │
│ ┃ ← 白の縦棒 17×484 @(128,154)                       │
└──────────────────────────────────────────┘
```

### F4：本文カードフレーム — P6〜P9、P12〜P21（本文はすべてこれ）
```
┌──────────────────────────────────────────┐ 背景 白
│ ページタイトル 42.67px bold #825dab @(82,40)   Tompedia(白)│ ← 帯 y=0〜122
│ ┌────────────────────────────────────┐ │
│ │ 白カード #fefefe 角丸 @(40,122) 1837×918（ロック）  │ │
│ │ 有効エリア：x 100〜1820、y 160〜1000                 │ │
│ └────────────────────────────────────┘ │
│ 背後に薄紫・紫の円が5つ（ロック）                         │
└──────────────────────────────────────────┘
```
- 背後の円：`#dfc7fa` Ø2723 @(-911,-1836)、`#825dab` Ø574 @(-81,722)、`#eedeff` Ø1550 @(211,-170)、`#8864af` Ø1277 @(1299,-672)、`#dfc7fa` Ø755 @(1327,418)。
- ページタイトルは「セクション名」「このページの話題」を短く書く場所（スライドの見出しではなく、パンくず的な役割）。メッセージは本文側の大見出しに書く。
- 右上のTompediaロゴ（白）は動かさない。

## 本文の組み方（F4の中）

### 見出し＋本文（P6／P12）
| 要素 | 位置・サイズ | 書式 |
|---|---|---|
| 縦棒 | (125,195) 9×223、`#825dab` | 見出しの左に置く。見出しが1行なら高さを約110に縮める |
| 大見出し（メッセージ） | (188,210) 幅1387 | 69px bold `#825dab`、行間1.6、字間0.05、2行まで |
| 本文 | (188,469) 幅1612 | 42.67px bold `#242323`、両端揃え、行間1.6、字間0.05 |

- 本文は1行約36文字。段落の間は1行空ける。改行は意味の切れ目で `\n` を明示する（P12の実例は1行30〜36文字で手動改行）。

### 写真全面（P8・P9・P15）
- 写真枠：shape（`isMediaReplaceable: true`）@(63,143) 1790×876。その上に暗幕 `#262626` 不透明度0.8を同じサイズで重ねる。
- 文字は白。P8/P9は中央揃え（小見出し 89px、大見出し 119px）。P15は左揃え（見出し 56px、本文 32px 行間2.0、x=156 幅1608）。

### 図解のパーツ（P13、P16〜P21、実例 `DAHXIFJiZ5I`）
- ボックス：角丸の四角（shape）。塗りは `#f6efff` / `#eddeff`（紫系）、部署色の淡色、`#dddddd`（グレー：現状・課題）。
- ボックスの中に文字を入れられる（shapeの `textContents`）。実例では 34.67px bold、`disc` の箇条書き、行間1.4。
- 矢印：`#825dab` の太い矢印（shape、パス `M0 32L32 0V16H64V48H32V64L0 32Z`）。
- ラベル帯：紫 `#835cab` や緑 `#44a803` の角丸帯に白文字（P16・P17）。
- 大きい数字：`YAFcfgcNhWk` 96〜126px、赤 `#ff3131` かマスタード `#cca300`。単位は 35px の黒（P14）。

## 文字数の上限（はみ出し防止）

1文字の幅 ≒ フォントサイズ × 1.05（字間0.05）として、テンプレートの枠幅から計算した値。英数字は全角の約0.6文字分で数える。

| 要素 | ページ | 1行あたり | 行数の上限 |
|---|---|---|---|
| 表紙タイトル（64px、幅863） | P1 | 12文字 | 1行（2行にするなら所属の行を下げる） |
| 表紙の所属・名前（56px） | P1・P2 | 13文字 | 2行 |
| How to 表紙の大文字（128px、幅764） | P2 | 英字 約8字／和文 5〜6文字 | 2行（実例は86pxに下げて幅1397、和文16文字×2行） |
| 営業部表紙（90.5px） | P3 | 9文字 | 部署名1行＋タイトル1行 |
| 目次の項目（64px、幅552） | P4 | 8文字（枠を幅900まで広げれば13文字） | 5項目（02〜04の間隔131px） |
| 扉の章タイトル（85px、幅826） | P5・P10 | 9文字 | 2行 |
| ページタイトル（42.67px） | F4共通 | 幅540で12文字／幅991で22文字／幅1217で27文字 | 1行 |
| 本文の大見出し（69px、幅1387） | P6・P12 | 19文字 | 2行 |
| 本文（42.67px、幅1612） | P6・P12 | 36文字 | 大見出し2行のとき7行（空行を含む） |
| 写真全面の大見出し（119px、幅≈1700） | P8・P9 | 14文字 | 1行 |
| 写真全面の本文（32px、幅1608） | P15 | 47文字 | 4行＋箇条4〜5行 |
| ボックス内の箇条書き（34.67px） | 実例 | ボックス幅1353で37文字 | 1ボックス5行 |

## 作るときの原則
1. 1スライド1メッセージ。ページタイトル（左上）は話題、大見出しはメッセージ、本文は根拠。
2. 箇条書きは1スライド3〜5項目、階層は2段まで。それ以上は2枚に分ける（`DAHX4IPSBko` のような文字びっしりのスライドを作らない）。
3. 色を足すのは強調の1〜2語だけ（緑か赤）。それ以外は紫・黒・白。
4. 装飾（ブロブ・円・カード・ロゴ・マスコット）は動かさない・色を変えない。
5. 写真を使うページで写真がない場合は、旧写真を残して「差し替えが必要」とリストで伝える。
