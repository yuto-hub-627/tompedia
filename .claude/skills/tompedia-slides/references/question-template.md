# 質問mdのひな形（資料ごと）

`aidlc-docs/slides-YYYYMMDD-<name>/01-questions.md` に、下をもとに書く。
依頼文や渡された資料からわかることは先に埋め、「この理解で合っていますか」と確認する形にする。わかりきっている質問は消す。

## 既定値（質問で変更がなければこれを使う）
| 項目 | 既定値 |
|---|---|
| 保存先フォルダ | 【02の回答で決める】 |
| デザイン名 | `YYYY-MM-DD_資料名` |
| CHECK!ページ | 入れない |
| スピーカーノート | 入れる |
| 写真 | ユーザーが渡したものだけ使う |

---

```markdown

依頼内容：〇〇（依頼文を1〜2行で要約）
各質問の `[Answer]:` の後ろに回答を書いてください（記号だけでもOK）。わからない項目は「不明」で大丈夫です。
```
