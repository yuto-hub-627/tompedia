# 開発背景・沿革

## 発足のきっかけ（代表 安部より）

安部は独学でプログラミングを学び、フリーランスとして活動していた。その中で「開発をしてみたいけど、1人だとちょっと大変」「スクールはわかりやすいけどお金がかかる」という声をよく聞き、途中で挫折する人を多く見てきた。これを解決して、**みんなで学び合って成長できる環境を作りたい**という思いから団体を立ち上げた。

STUDENT DEMODAY 2024 での説明：

- **ソフトウェア開発を学ぶ場が不足していた**：東北大学には、ソフトウェア・ウェブ開発を学べるサークルや団体が少なく、独学するしかない。「関心はあるけど1人で学ぶのは挫折した」学生がたくさんいる。
- **皆で開発を学び合い成長できる場を作ってみた**：教え合い・学び合いで挫折せずにスキルを身につける場をまず作った。人が集まり技術力がついてきたところで「何か新しいものを作ろう」という話になった。
- 「まずはソフトウェアエンジニアコミュニティから！」

代表の経歴（キックオフ資料）：山形県米沢市出身。工学部情報物理→大学院情報科学研究科。ロケットサークルで組み込み→IoT→Web。Yahoo! 学生ハッカソン優勝。塾を立ち上げ、今も株式会社shared として活動。仕送りなし・学費も自分で払う生活が自分を強くした（でも一人でやるのは寂しいし大変）。

## アプリ開発の背景（解決したい課題）

- **大学生活に関する情報不足**、**大学公式サイトの使いにくさ**（ラボ紹介資料）
- **情報の不公平性による機会損失**（LT資料 2026-03）
- **留学や奨学金情報の分散による機会損失**（企業向け資料 2025-05）
- 具体例（DEMODAY・提案資料）：時間割を作るときにシラバスを探すのに時間がかかる。成績が出ても自分の GPA を知る方法がない。東北大学は DX が進んでいる方だが、情報にアクセスしづらい。Google Classroom・ISTU・学務情報システム・学科ごとの掲示板など情報源が多く、見逃してしまう。
- 解決策：**東北大生が欲しかった機能を詰め込んだアプリ**。学生に不便なところを聞いて、それを解決する機能を作った（シラバスと鬼仏表の統合、GPA計算機、卒業要件チェック、学割のお店・クーポンなど）。

キックオフ資料の流れ：エンジニアコミュニティでプロダクトを作りビジコンに出場したが PMF に失敗 → 「実際に何か作った方が勉強になる！」→ 次は東北大生向けの時間割アプリを作ろうとした → とんペディアの誕生。当時、代表 安部は3年生、営業リーダー荒木・開発リーダー千葉は学部1年生。初心者がほとんどで10人くらいで活動していた。
