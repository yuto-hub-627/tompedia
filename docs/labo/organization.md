# 組織

## 全体像（とんペディアを取り巻く環境）

| | 学生団体 とんペディア_ラボ | 一般社団法人 とんペディア |
|---|---|---|
| 運営 | すべて学生が運営 | とんペディア創始者が運営 |
| 役割 | アプリ開発・広報・法人営業。東北大生のニーズを拾い上げてアプリに反映する | 企業との契約の媒体。学生団体とアプリ運営の責任をとる |

アプリに対して、ラボは「運営」、法人は「責任」、法人からラボへは「後見」の関係。

### 一般社団法人とんペディア

- 2025年11月10日に設立（営利型）。メンバーは4人で報酬はなし
- 目的：ラボの継続的な運営のため、もっと面白いことをやっていくため
- 企業との取引やアプリの法的責任・賠償責任は法人が持つ
- 役割：法人・スポンサーとの契約締結、ラボの運営資金の提供、ラボの安定した運営のサポート
- ラボの代表は毎年交代、法人の運営陣は継続

## プロジェクト制

- プロジェクト単位で予算や人員を配置して活動する。誰でもプロジェクトを立ち上げられる。費用は基本ラボが負担
- 立ち上げ方：企画書（背景と目的、概要、必要なもの・資金）を作り、各部署から何人必要かを決めて各部リーダーに確認 → 代表の承認でスタート。先輩が企画書や設計の壁打ちをしてくれる
- 目標はサクセスクライテリア（ミニマム < フル < エクストラ）で決める（例：スプフェスのブース）
- メインは「とんペディアプロジェクト」（アプリの運営、全員参加）。ほかは参加任意
- 他のプロジェクトの例：umami_flutter（OSS の SDK 開発）、量子アニーリングで研究室を提案、Kytos orchestration、とん平の部屋（VSCode 拡張）、Futon Navi（旅館の布団敷き DX）、T-Portal（内部ポータル：名刺管理・議事録・GitHub 連携）、東北大生向けコミュニティ掲示板、Tompex、ゲームプロジェクト（Unity）
