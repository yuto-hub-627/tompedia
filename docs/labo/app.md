# アプリ「とんペディア」

東北大生のための学生アプリ（大学非公式）。「東北大生が欲しかった機能を詰め込んだ学生アプリ」。iOS・Android・Web。

## 機能

- 時間割
- 鬼仏表（授業評価掲示板。鬼＝厳しい／仏＝やさしい授業の口コミ）
- シラバス検索（シラバスと鬼仏表を統合して、すぐ授業を検索できる）
- サークル紹介
- GPA計算機、卒業要件チェック
- 空き教室検索（空き時間の有効活用に大人気）
- 地下鉄・バス時刻表（あと何秒で地下鉄やバスが到着するか分かる）
- イベント掲示板（東北大学内・仙台市内のイベント）
- サークル紹介・新歓カレンダー（学友会・非公認・インカレの200団体以上。カレンダーアプリと連携）
- 時間割はクォーター授業・集中講義に対応。Classroom との連携、ウィジェット
- 初期は学割のお店の紹介・とんペディア限定クーポン、各種ニュースも
- 開発中・構想（キックオフ資料）：掲示板、キャンパスマップ、Unity のゲーム

## これから実現したいこと（企業向け資料 2025）

1. ユーザー数の拡大：約3,700人 → 1年後に6,000人（東北大生の半数以上）
2. 学生生活の利便性の向上：AI などを使った機能。「とんペディアで学生生活が便利になった」学生を80%以上に
3. 情報格差の解消：「知らなかったインターン・学内イベント情報を知れた」学生を80%以上に

DEMODAY（2024-12）では、ユーザー1,000→5,000人（学部生の50%）、利用する大学を増やす、が展望だった。
