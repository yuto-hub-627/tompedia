# 文化・ルール

## 火曜全体会のこれから（2026年秋・幹部からの共有）

- 今の課題：聞く時間が長い／PC で別作業をする人が増えて集中しにくい／連絡・定型報告だけなら対面の必然性が弱い
- 考え方：「今日の作業量」だけを最大化したいわけではない。今日生まれる価値（タスク・成果物）と、これから生まれる価値（新しい協力・挑戦）の両方が必要
- 目指す活動の姿勢：気づく → 話す → 試す → 直す のサイクルを、メンバー自身が回す
- 関係性が必要な理由：誰と一緒にいるかを知る／相談・協力の選択肢が増える／率直な議論ができる／雑談から次のプロジェクトの種が生まれる
- 火曜日は「報告を聞く日」から「一緒に考え、動く日」へ：①共有する ②話し合う ③一緒に動く
- チェックインは、全員が「聞く人」から「話す人」になる小さな入口。友達になることを強制したいわけではない
- 運営の責任：意見を歓迎する・意見を扱う・実行につなげる
- 形は幹部だけで決めず、「まず試す → 意見を聞く → 形を見直す」

## 公式キャラクター「とん平」

- 紫色のパーカーを着たぶた。すご腕のエンジニアで、生粋の夜型（朝9時に眠る）
- 緑色のローテーブル、自作 PC、HHKB、デュアルモニター。ゲーミングチェアは足が届かないので、紫の座布団に座る
- 「とんぺい焼き」は NG（見ると不機嫌になる）
- LINE スタンプあり。部室の守り神
- 新入生には、自分で作ったとん平入りの名刺をプレゼント（T-Portal で作成 → Discord の名刺作成チャンネルで SVG にしてもらう）
- 使い方の決まりは、Google ドライブの「とん平 公式デザインガイドライン」
