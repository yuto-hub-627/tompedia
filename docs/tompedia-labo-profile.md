## 1. 紹介文

### 標準版（400字程度）

> **東北大生の「当たり前」をつくる、学生アプリ開発団体**
>
> とんペディア_ラボは、東北大学の学生向けアプリ「とんペディア」を開発・運営している学生団体です。東北大学学友会に登録されています。「大学生活に関する情報が足りない」「大学公式サイトが使いにくい」という学生自身の不満から生まれ、東北大生が欲しかった機能を一つのアプリにまとめています。
>
> アプリには、シラバスと連携した時間割作成、在学生による授業評価「鬼仏表」、GPA計算、空き教室検索、部活・サークル紹介、イベント掲示板、地下鉄・バスの時刻表などの機能があります。2026年7月時点で利用者は6,720名を超え、今年度の新入生の登録率は95%に達しています。
>
> ラボのメンバーは開発・デザイン・広報・営業などのチームに分かれ、プログラミングやマーケティング、企業営業を互いに教え合いながら、実際のサービス運営を通して身につけています。サーバー代などの運営費は企業の広告と協賛金でまかない、得た資金でサービスの改善やイベントの企画を続けています。私たちが目指すのは、東北大生と仙台の企業がもっと交流し、東北大生が宮城・仙台に誇りを持てる未来です。

### 短縮版（SNS・チラシ向け）

> 東北大生の大学生活を、もっと便利に、もっと面白く。とんペディア_ラボは、新入生の95%が登録する学生アプリ「とんペディア」を開発・運営する学生団体です。時間割、鬼仏表、空き教室検索、サークル情報、バス・地下鉄の時刻表まで、東北大生に必要な情報を一つのアプリにまとめています。開発・デザイン・広報・営業を学び合いながら、仙台の企業とつながるイベントも企画しています。

### 理念・ビジョン

- **ミッション**：東北大生が自分のやりたいことを、もっともっとできるようにする
  - 東北大生がもっと勉強に集中できる、部活に集中できる
  - 大学だけでなく、私生活も楽しめる
- **2本の柱**
  1. **大学生活を便利にするアプリ開発**
  2. **学び合い高め合うコミュニティ**：アプリ開発、マーケティング、プロジェクトマネジメントなどの実践的なスキルを、学生が主体的に身につけ、将来につながる経験を得る
- **VISION**：東北大生がもっと宮城・仙台に誇りを持てる未来
  - 東北大生と仙台の企業がもっと交流する社会を目指す。東京での就職を否定するのではなく、「そもそも仙台の企業と交流する機会がないこと」「いつか宮城に戻ってこようと思えないこと」を課題ととらえ、とんペディアで解決していく

### 体制（チーム）

| チーム | 主な役割 |
|---|---|
| Webバックエンド開発 | サーバー・API の開発 |
| Webフロントエンド開発 | 画面の開発 |
| モバイル開発 | iOS／Android アプリの開発 |
| 営業 | 企業とのコラボ、スポンサー獲得、イベントの企画・運営 |
| 広報 | SNS 発信、紹介コンテンツの制作 |

人数の内訳は紹介スライド時点で「Webバックエンド5／モバイル5／Webフロント3／営業6／広報12」。

### 運営の仕組み

- サーバー代やシステム利用料（月に数万円）を、**企業の広告と協賛金**でまかなう
- 得た資金をサービス改善や新しいイベントに回す、という循環で運営している

## 4. アプリ「とんペディア」

### 概要

- 東北大学の学生が開発した、東北大生のための**非公式**学生アプリ（大学公式の「東北大アプリ」とは別物）
- コンセプト：**東北大生が欲しかった機能を詰め込んだ学生アプリ**
- 開発のきっかけ：大学生活に関する情報の不足、情報の不公平さによる機会損失、大学公式サイトの使いにくさ
- 配信：App Store で確認済み（Google Play での配信状況は未確認）

### 機能一覧

| 機能 | 内容 |
|---|---|
| 時間割 | シラバスと連携し、アプリ内の操作だけで時間割を作れる。全学教育から専門科目、大学院まで登録可能。色の変更にも対応 |
| シラバス検索 | 東北大学の授業をアプリ内で検索できる |
| 鬼仏表 | 在学生が授業の難しさ・評価を投稿・確認できる授業評価掲示板 |
| GPA計算機 | 学務情報システムの成績表を貼り付けるだけで GPA を計算 |
| 空き教室検索 | 川内キャンパス講義棟の空き教室を検索。空きコマの過ごし方を探すのに人気 |
| 地下鉄・バス時刻表 | 地下鉄・学内バスがあと何秒で来るかがわかる |
| サークル紹介 | 部活・サークルの情報を検索できる。新歓にも活用されている |
| イベント掲示板 | イベントカレンダーとイベント詳細 |
| トピックス | お知らせ・記事 |

### 利用状況

| 指標 | 値 |
|---|---|
| ユーザー数 | 6,720名（2026年7月時点） |
| 今年度新入生の登録率 | 95% |
| 学部2年生の登録率 | 82% |
| 全学部生の登録率 | 67% |
| DAU | 約1,800人/日（紹介スライドの時点では平均約1,000） |
