# とんペディア スライドのデザインガイド

とんペディア／とんペディア_ラボのスライド（16:9）のデザインの決まり。元は Canva の「とんペディア テンプレート」。

- デザインシステム（claude.ai）：https://claude.ai/artifact/KHP9tBpsfqWhsaXkfG7ZYA （色・文字・ロゴ・マスコット・全ページの見本）
- 元のテンプレート（Canva）：[とんペディア テンプレート（22ページ）](https://www.canva.com/d/meZR_R_yFZmYBeV)／[短い版（4ページ）](https://www.canva.com/d/5yFeQ4LBiWF7vpR)／[MD対応用（20ページ）](https://www.canva.com/d/oi4Fnd5-WWPMfDg)
- 新しいスライドは、テンプレートの近いページを Canva で複製して作る。保存先は Canva の「とんペディアラボ」フォルダ。
- **注意（2026-11-22）**：上の Canva のリンク（テンプレート）は、以前連携していたとんペディアラボのアカウントのもの。今は中西悠仁の個人アカウントに切り替えたので、Claude からは読めない

## まず守ること

- キャンバスは 1920×1080。この本に書いた文字の大きさ・余白はすべてこの大きさでの値。
- 色は `purple` がメイン、`green` がサブ。背景は白（`surface`）と薄い紫（`lavender-100`・`lavender-200`）。
- 形は「やわらかい」：波のような丸い形（ブロブ）と、角丸の白いカード（`radius-card`）。角ばった枠や影は使わない。
- 1枚に言いたいことは1つ。強調の色（`red`・`green`）は1枚に1〜2か所まで。

## 色

- 見出し、ロゴ、ページ名、Contents は `purple`。文字は `ink`、補足は `ink-muted`。
- 本文ページの地は `lavender-200`、四隅に `purple` と `lavender-300` のブロブを置き、その上に白いカード（`surface`）を乗せる。
- `green` はラボの芽の色。行動指針の強調語（幸せ・成長・つながる）、ラボの年表、「運営」などに使う。白の上で 3.07:1 なので、24px 以上の太字だけ。
- 数字や結論の強調は `red`（例：6,720名、100人規模）。白の上で 4.02:1 なので太字の大きな文字で。
- 部署やグループを色で分けるときは、営業＝`orange`（地は `orange-tint`）、開発・ラボ＝`green`（地は `green-tint`）、広報・法人＝`blue`。
- `orange` は白の上で 2.71:1 と薄い（元のテンプレートのまま）。営業部の表紙の大きなタイトルとタイル以外では文字に使わない。

## 文字

- フォントは「Zen Maru Gothic」（`sans`）。太さを選べる丸ゴシックで、テンプレートの文字はこれ。ほかに「Kosugi Maru」と「つなぎゴシック」もたまに使うが、役割は決めていない。迷ったら Zen Maru Gothic。
- 太さは、見出しが 900（heavy）・700（bold）、本文も 700。細い文字は機能名などのラベル（`label`）だけ。
- 大見出しと表紙は行間 1.6・字間 0.05em、本文ページの文字は行間 1.4。
- 大きさの段：`chapter-number` 199 → `display` 128 → `big-number` 140 → `photo-title` 118 → `sales-title` 90 → `chapter-title` 85 → `card-heading` 69 → `cover-title` 64 → `statement` 60 → `byline` 56 → `lead` 47 → `page-label` 43 → `body` 42 → `label` 31 → `small` 28 → `caption` 20。`caption` より小さくしない。

## 余白と角丸

- 本文ページ：上の帯の高さは `slide-header`（122px）。帯の左にページ名（`page-label`）、右にロゴ。
- 白いカードはスライドの端から `slide-inset`（42px）あけ、角丸は `radius-card`（40px）。カードの中の余白は `card-padding`（80px）。
- カードの中の部品のすき間は `gap`（40px）。小さなカード・写真は `radius-md`、ラベルは `radius-sm`。
- 見出しの左には `purple` の縦線をつける（カードの中・章トビラ）。

## 形

- ブロブ（波の形）：表紙・目次・章トビラ・本文ページの背景の飾り。色は `purple`・`lavender-300`・`lavender-200`。文字の後ろには置かない。
- 花のマーク：表紙・目次の右下に、白で大きく置く（ロゴの花と同じ形）。新しく描かず、Canva の元の素材を使う。
- 営業部だけは、`purple` と `orange` の角丸の四角を斜めに並べたタイル柄を使う。

## ロゴとマスコット

- アプリの話は `tompedia-app-logo`、団体の話は `tompedia-labo-logo-jp`、最後のページは `tompedia-labo-logo`、本文ページの右上は `tompedia-mark-small`。ロゴの色・形は変えない。
- マスコットは「とん平」（紫のパーカーのぶた）。1枚に1匹まで、文の意味に合うポーズ（つくろう・まなぼう・つながろう・CHECK）を選ぶ。

## 素材の置き場所

- ロゴ・とん平のイラストの元ファイルは Google ドライブの「tompedia / とんペディアラボ画像素材」にある（ロゴは「ロゴ等」、とん平は「とん平 イラスト全集」など）。この本のロゴととん平は、テンプレートの画像から切り抜いた見本。大きく使うときや新しく作るときは、ドライブの元ファイルを使う。
- とん平の使い方は、ドライブの「とん平 公式デザインガイドライン」に従う。

## 写真

- 写真は白いカードの枠いっぱいに入れ、文字を乗せるときは暗い幕を重ねて白い文字にする。
- 人の写真は、楽しそうな集合写真や作業中の様子を使う。

## 書き方

- 「です・ます」で書く。見出しは短く、体言止めでよい（例：「とんペディアを取り巻く環境」）。
- 数字は大きく、単位は小さく（例：6,720 名）。
- 団体名は「とんペディア_ラボ」（アンダーバーつき）、アプリは「とんペディア」、英語は「Tompedia」「Tompedia Labo」と書く。

## ページの型

19 の型をコンポーネントとしてまとめた（表紙・構成・本文・写真・数字・図解・人・締め）。それぞれの README に元のページと決まりを書いた。テンプレートの全ページの画像は `assets/Pages/`。
